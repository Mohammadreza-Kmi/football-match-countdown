# Footbal Match Countdown
Right now, it only shows the upcoming match for Barcelona. It shows the team they are playing against and how much time left until kickoff.

## How to run
1. Clone the repo
2. pip install -r requirements.txt
3. Get a free API key from football-data.org (takes two minutes) and add it to a .env file like this:
   API_KEY=your_key_here
4. python football_tracker.py
